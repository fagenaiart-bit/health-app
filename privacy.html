Коротко

Твої медичні дані зберігаються тільки на твоєму Google Drive. Ми не маємо бази даних з твоїми даними й не бачимо їх.

Які дані обробляє застосунок

  • Те, що ти вносиш сам(а): аналізи, візити, ліки, тиск, вагу, нотатки, документи (PDF чи фото).
  • Від Google при вході: твій email, ім'я та фото профілю — щоб показати, хто увійшов.

Де зберігаються дані

  • У папці «health.» на твоєму Google Drive: файл health-data.json і завантажені документи.
  • Копія в твоєму браузері — для швидкості й роботи без інтернету. Вона видаляється, якщо очистити дані сайту.

Доступ до Google Drive

Застосунок просить лише дозвіл drive.file: він бачить тільки ті файли, які створив сам (папку «health.» і документи, додані через застосунок). До решти твого Drive доступу немає.

Використання даних, отриманих через Google API, відповідає Google API Services User Data Policy, включно з вимогами Limited Use. Ми не передаємо ці дані третім особам, не використовуємо їх для реклами й не навчаємо на них моделі AI.

Читання документів через AI

  • «Мій ChatGPT»: ти сам(а) завантажуєш документ у свій ChatGPT. Через сервери health. нічого не проходить. Діють правила OpenAI для твого акаунта.
  • «AI від health.»: файл передається через наш сервер до OpenAI API, щоб розпізнати показники, і одразу повертається тобі. Ні сервер, ні застосунок не зберігають файл чи результат. OpenAI API обробляє запит за своїми правилами для API (дані API не використовуються для навчання моделей за замовчуванням).

AI лише переносить цифри з документа. Застосунок не ставить діагнозів і не дає медичних порад.

Твій контроль

  • Видалити все: видали папку «health.» на Google Drive і вийди із застосунку.
  • Відкликати доступ: myaccount.google.com/permissions.
  • Резервна копія: Налаштування → «Завантажити копію (.json)».

Privacy policy

Updated 25 October 2026 · health. is an app by me20 Studio, Warsaw

In short

Your medical data is stored only on your own Google Drive. We have no database with your data and we cannot see it.

What the app processes

  • What you enter: lab results, visits, medicines, blood pressure, weight, notes, documents (PDF or photos).
  • From Google at sign-in: your email, name and profile picture, to show who is signed in.

Where data is stored

  • In the «health.» folder on your Google Drive: the file health-data.json and the documents you add.
  • A copy in your browser for speed and offline use. It is removed when you clear the site's data.

Google Drive access

The app requests only the drive.file scope: it can see only files it created (the «health.» folder and documents added through the app). It has no access to the rest of your Drive.

health.'s use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. We do not share this data with third parties, use it for advertising, or use it to train AI models.

Reading documents with AI

  • «My ChatGPT»: you upload the document to your own ChatGPT. Nothing passes through health. servers. OpenAI's terms for your account apply.
  • «health. AI»: the file is sent through our server to the OpenAI API to read the values and the result goes straight back to you. Neither the server nor the app stores the file or the result. The OpenAI API processes the request under its API terms (API data is not used to train models by default).

The AI only transfers numbers from the document. The app makes no diagnoses and gives no medical advice.

Your control

  • Delete everything: delete the «health.» folder on Google Drive and sign out.
  • Revoke access: myaccount.google.com/permissions.
  • Backup: Settings → «Download a copy (.json)».
